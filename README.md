# pogoda

Десктопное приложение для просмотра текущей погоды и прогноза на 3 дня с практическими рекомендациями (нужен ли зонт, тёплая одежда, головной убор).

## Формулировка проблемы

Когда человеку нужно спланировать день с активностями на улице, он тратит время на изучение перегруженных погодных сервисов с рекламой и обилием лишней информации, из-за чего не может быстро принять простое решение — как одеться и что взять с собой.
=> Проблема: Отсутствие простого инструмента для быстрой оценки погоды и получения практических рекомендаций.

## Возможности

- Поиск погоды по названию города.
- Текущая погода: температура, ощущаемая температура, влажность, скорость ветра.
- Прогноз на 3 дня с вероятностью осадков.
- Практические рекомендации на основе погодных данных.
- Кэширование запросов в локальную базу данных (данные хранятся 30 минут).
- Логирование всех действий приложения.

---

## Стек

- Язык: Python 3
- Интерфейс: Tkinter
- База данных: SQLite (кэширование запросов)
- API: Open-Meteo (публичное, без ключа)
- HTTP-запросы: библиотека requests

## Установка

1. Клонировать репозиторий:

   ```
   git clone https://github.com/zaxarr13/pogoda.git
   cd pogoda
   ```

2. Установить зависимости:

   ```
   pip install -r requirements.txt
   ```

## Логирование

Все действия приложения (запросы к API, работа с кэшем, ошибки) записываются в файл `app.log` с указанием времени и уровня события.

## Источник данных

Данные о погоде предоставляются публичным API [Open-Meteo](https://open-meteo.com) — бесплатным сервисом прогноза погоды, не требующим ключа доступа.
